# Brand files

For Stripe, app stores and other places that need a picture of TardiGeddon.
Made from the game's own artwork (`public/icon.svg`, the mascot in
`src/ui/mascot.ts`, the Luckiest Guy title font).

| File | Use |
|---|---|
| `tardigeddon-icon-512.png` | Square icon, 512×512 (Stripe "Icon", app/store icons) |
| `tardigeddon-logo.png` | Mascot + wordmark on a transparent background (Stripe "Logo") |

## Colours (docs/STYLE_GUIDE.md)

| Name | Hex | Use |
|---|---|---|
| Red | `#e04848` | "Tardi" in the title, main brand colour |
| Yellow | `#ffd84a` | "Geddon", buttons, highlights |
| Sky blue | `#7fd3f7` | Backgrounds, icon |
| Ink | `#2b1b24` | Outlines and text |
| Paper | `#fff8ec` | Panels |
